# Clínica Santa Elizabeth — Sitio web

Sitio institucional y comercial desarrollado en HTML, CSS y JavaScript sin dependencias externas.

## Catálogo incorporado

- Cirugía general y laparoscópica: COLELAP, APENDILAP y cirugía de hernias.
- Atención de partos y cesáreas.
- Centro quirúrgico con dos salas de operaciones.
- Laboratorio clínico.
- Farmacia.
- Ecografías 6D.
- Banco de sangre.
- Centro de esterilización.
- Lavandería clínica.
- Servicio de ambulancia.
- Atención clínica integral y consulta por otros servicios.

## Características del sitio

- Diseño responsive para móviles, tabletas y escritorio.
- Portada comercial con llamadas a la acción.
- Catálogo organizado en fichas de servicios.
- Presentación institucional.
- Formulario demostrativo de contacto.
- Navegación móvil accesible.
- Avisos informativos sobre disponibilidad y evaluación profesional.

## Pendiente antes de publicar

1. Incorporar dirección, teléfonos, WhatsApp y correo institucional oficiales.
2. Conectar el formulario a un backend, CRM o canal autorizado.
3. Incorporar fotografías reales, logotipo oficial y material institucional aprobado.
4. Validar las denominaciones y alcances de los servicios, así como las autorizaciones y requisitos aplicables.
5. Revisar política de privacidad, tratamiento de datos personales y avisos legales.
6. Confirmar horarios, cobertura y condiciones del servicio de ambulancia.

## Vista local

Abrir `index.html` en un navegador.

La información publicada es referencial y no sustituye la evaluación médica. Los servicios se encuentran sujetos a indicación profesional, disponibilidad y requisitos aplicables.
