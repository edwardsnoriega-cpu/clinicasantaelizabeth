# Clínica Santa Elizabeth — Sitio web

Primera versión de la página institucional y comercial, desarrollada en HTML, CSS y JavaScript sin dependencias externas.

## Incluye
- Diseño responsive para móviles, tabletas y escritorio.
- Portada comercial con llamadas a la acción.
- Sección de servicios preparada para el catálogo oficial.
- Presentación institucional.
- Formulario demostrativo de contacto.
- Navegación móvil accesible.

## Para completar antes de publicar
1. Sustituir las descripciones provisionales por el catálogo real de servicios y productos.
2. Incorporar dirección, teléfonos, correo y canales oficiales de atención.
3. Conectar el formulario a un backend, CRM o servicio autorizado.
4. Incorporar fotografías, logotipo oficial y datos institucionales aprobados.
5. Revisar textos, privacidad y avisos legales antes de producción.

## Vista local
Abrir `index.html` en un navegador.
